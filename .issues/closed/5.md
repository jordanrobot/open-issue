- [X] Within the Open Issue windows app, autosave as the user edits the issues. Remove the explicit Save button.- [X] ensure that all changes are saved automatically without requiring user intervention.- [X] provide visual feedback to the user indicating that changes have been saved successfully.- [X] handle potential conflicts when multiple edits occur simultaneously, ensuring data integrity. Ask the user how to resolve conflicts when they arise.- [X] autosave should happen 100 ms after the last change made by the user.- [X] ensure that autosave works consistently across all fields and input types within the issue editor.- [X] Ensure the issue's data is updated if the user clicks away from the issue and then clicks back to it. During initial testing of the prelim implementation, the issue body was not being refreshed correctly, and the user saw an older version of the issue's text.
