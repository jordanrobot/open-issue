# Desired outcome

# Acceptance criteria

- [ ] Change UI to winUI3
- [ ] It should provide the rough interface we have in the current windows app.
  - [ ] issue list on the left
  - [ ] search and filters on the issues
    - [ ] status, priority, user name, tags, "drafts only", "no drafts"
  - [ ] Issue text edit area on right. show selected issue's contents and make available for editing.
  - [ ] Markdown editing within issue text.
    - [ ] When entering on a list, continue the list when pressing enter.
    - [ ] If user presses enter on an empty list item, remove the list item for that line.
    - [ ] Save behavior for markdown checkboxes
- [ ] display metadata

- [ ] Allow linking between issues by editing parent and child relationships.
  - [ ] Show "add parent(s)" button that when pressed shows all open issues for the user to select one. That item is made a parent to the current note.
  - [ ] Show "add child" button that when pressed shows all open issues for the user to select from. Those item(s) are made a child of the current note.

- [ ] Allow "tags" to be added to issues. These are user-defined text categories/keywords/etc.
- [ ] When users are adding tags, existing tags should be shown as valid options.
- [ ] Users may enter custom text as a new tag.
- [ ] Users should be able to search and filter on tags.
- [ ] user may add tags inline of the issue body text by entering the following `#text`.
- [ ] this differs from creating links to other issues within the issue body, which should follow the form `#number`
