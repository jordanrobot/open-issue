- [ ] Allow "tags" to be added to issues. These are user-defined text categories/keywords/etc.- [ ] When users are adding tags, existing tags should be shown as valid options.- [ ] Users may enter custom text as a new tag.- [ ] Users should be able to search and filter on tags.- [ ] user may add tags inline of the issue body text by entering the following `#text`.- [ ] this differs from creating links to other issues within the issue body, which should follow the form `#number`
