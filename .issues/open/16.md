- [x] Allow the user to reorder the issue list by drag and dropping the issues within the list.- [x] Persist the sort order between application sessions.- [x] Allow manipulation of child/parent relationships by dragging and dropping issues within the issue list onto and underneath other issues.  - [x] i.e. this list should become a tree view.  - [x] dragging an issue under another shall set up a child-parent relationship between those issues.- [ ] When dragging and showing the temporary "insertion/placement bar", if the user'd mouse cursor is closer to the left side of the box, the issue should be moved nearer the root of the list (not a child). Display the insertion bar extending farther to the left (into the indent area) when the issue is being moved "up" a level in the heirachical structure.- [ ] when dragging an issue into another (as a child) show the insertion bar indented to indicate it's going to be a child. - [ ] When dragging an issue in the list, do not show a blank area between items. Instead, just move the insertion bar between the lines. This should be the user indication of the destination placement of the issue currently being dragged.
